Sınırlamalar ve yöntem

Timeline includes file metadata, explicit RFC3339/JSONL timestamps and supported PCAP packet timestamps; these are not proof of execution or user attribution.

Rules are literal matches, not malware verdicts. Every finding requires analyst review.

Text scanning covers UTF-8 files up to 8 MiB each, 128 MiB total; classic PCAP is parsed separately; other binary formats are inventoried, not parsed.

Clock offsets are not measured. Timestamps reflect the source host clock converted to UTC.

PCAP: classic v2.4 Ethernet/raw-IP TCP/UDP headers only. No capture, payload inspection, checksums, reassembly, DNS resolution or session reconstruction. Directional five-tuples group all matching packets within one evidence object; MAC/VLAN identity is not part of the grouping; retransmissions and repeated sessions are not deduplicated. Byte counters are recorded frame sizes, not application traffic. Each capture is limited to 64 MiB and 20,000 records, 256 MiB total, shared 50,000 log-event/capture-record budget, 10,000 flows total and 20 references per flow. See capture summaries for omissions; IP addresses do not identify people.

Correlations are shared field values across at least two evidence objects, not independent-source corroboration or identity attribution. NAT, shared accounts and duplicate logs can produce matches. User names are case-sensitive; host names lowercased; IPs canonicalized. No network enrichment is performed.

Ham delil değiştirilmeden incelendi. Rapordan orijinal kayıtları doğrulamak için delil kimliği, kaynak yolu ve SHA-256 kullanılmalıdır. HTML tarayıcının yazdır işleviyle PDF olarak kaydedilebilir.
